# 🌐 HIS Global Conclave Edition 2
### *Fostering Global Dialogue for a Better Future*

Official MUN website of **Hindustan International School, Karapakkam**, built for **HIS Global Conclave Edition 2** — a Model United Nations event promoting diplomacy, debate, and international collaboration among students.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|--------|
| Next.js | Full-stack React framework used for routing, static site generation (SSG), and app structure |
| TypeScript | Static typing for better scalability and maintainability |
| Tailwind CSS | Utility-first CSS framework for responsive UI design |
| React | Component-based UI library used via Next.js for client-side interactivity |
| Vercel | Deployment platform with global CDN for fast delivery |
